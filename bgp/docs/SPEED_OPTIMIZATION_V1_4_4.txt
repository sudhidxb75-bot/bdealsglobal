============================================================
V1.4.4 SPEED OPTIMIZATION NOTE
============================================================
This version reduces slow backend loading by:
1. Combining public Countries + Banners + Properties into one Apps Script action: publicData.
2. Showing cached/sample public data immediately instead of waiting on Google Apps Script.
3. Refreshing backend data in the background when the backend responds.
4. Removing full setupSheetsIfMissing() execution from every public read request.
5. Adding a frontend timeout message for very slow Apps Script responses.
6. Adding a Clear Frontend Cache button in backend-test.html.

After replacing files:
- Replace apps-script/Code.gs in Google Apps Script.
- Run setupSheets() once manually from Apps Script.
- Deploy a NEW Web App version.
- Upload all website files, especially js/main.js and service-worker.js.
- Clear browser/PWA cache once or reinstall the PWA.
- Open backend-test.html and check "Public Data Combined".

Recommended Google Sheet hygiene for speed:
- Keep only approved/live listings in Properties; archive old/closed records.
- Avoid very large image URLs or long notes in public listing rows.
- Use direct compressed image URLs for banners and properties.
- Do not keep thousands of blank formatted rows in Google Sheets.
